Project Description

AI Vibe Examiner is an interactive personality assessment tool that asks users a series of situational questions while analyzing their facial reactions via webcam. Instead of providing actionable psychological insights, it uses computer vision to evaluate user hesitation metrics, then roasts their choices using iconic Malayalam comedy dialogues.

The Problem (that doesn't exist)

Standard personality quizzes fail to aggressively judge you while you are taking them. Users currently lack an automated system that monitors their facial expressions, flags their micro-hesitations during simple multiple-choice questions, and publicly undermines their decision-making skills in real time.

The Solution (that nobody asked for)

We built a web application that presents seemingly innocent questions while running MediaPipe face mesh tracking in the background. The moment you hesitate or select a questionable answer, the system calculates your "Vibe Vulnerability" score and interrupts your quiz by playing loud audio clips of Salim Kumar, Jagathy, and Sreenivasan roasting your choices.
